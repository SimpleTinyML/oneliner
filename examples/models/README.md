# Example models

Fixtures used by the standard-host end-to-end tests and the example projects.
Only the models in the first group are exercised by automated tests; see
`tests/std/README.md` for the target/feature matrix.

| File | Used by | Notes |
| --- | --- | --- |
| `abs2.mlir` | `tests/std` (`host-e2e`) | Hand-written MLIR (`math.absf` on 2xf32); lightweight MLIR entry check. |
| `lenet5_quantized.onnx` | `tests/std` (`host-e2e`) | Quantized LeNet5, ONNX importer. |
| `lenet5_pytorch.pt2` | `tests/std` (`host-e2e`) | Exported program regenerated by `export_lenet5_pytorch.py`. |
| `lenet5_tensorflow/` | `tests/std` (`host-e2e`) | SavedModel v2 regenerated by `export_lenet5_tensorflow.py`. |
| `lenet5_quantized.tflite` | `tests/std` (`host-e2e`), examples | Quantized LeNet5; also the single shared-arena E2E representative. |
| `mcunet-10fps_vww.tflite` | `tests/std` (`host-e2e`), `examples/std-minimal` | MCUNet visual-wake-word int8; large-model regression. |
| `mcunet_10fps_vww.mlir` | manual only | Legacy pre-converted MLIR of the same MCUNet network. |
